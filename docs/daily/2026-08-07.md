**成熟度**: 项目版本未标注但生态活跃，作者有 6 万订阅者、官方插件市场已收录，技能文件迭代频繁，基本可用但部分技能仍在演进。

**成熟度**: 较成熟：已有 npm、Homebrew、桌面安装包和 VS Code 扩展等稳定分发渠道，文档齐全，CI 和社区活跃，但未见明确版本号，API 仍可能调整。

**趋势信号**: DeepSeek 模型近期热度极高，而 API 成本是长会话的痛点；这个项目精准打出『前缀缓存稳定性』这张牌，配合多端发布，恰好踩中 AI 编程助手降本增效的社区情绪。
