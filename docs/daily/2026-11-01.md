### [thedotmack/claude-mem](https://github.com/thedotmack/claude-mem)

 `TypeScript` ⭐ +1,723 今日新增 · 108,145 总星数

> 给 AI 编程助手加长期记忆：自动记录会话中的工具调用，用 AI 压缩成摘要，下次会话自动注入相关上下文，省去重复交代项目背景。

**亮点**

- 注入方式是与宿主已有的读文件习惯配合，不另外加一层召回：把关键结论写成带日期的一行追加到日志文件，宿主下一轮自己读到，因此省掉 embedding 检索和提示词拼接。
- 安装器按宿主分别注册原生插件和 hook（Claude Code hook、OpenCode 2、T3 Code 的多 provider、Antigravity、Pi 扩展），一套 CLI 覆盖七八个 Agent 运行时，接入方式因宿主而异。
- 把记忆计算放到你的套餐额度之外（自建 observer 或自己的 API key），这是它区别于纯开源记忆库的商业点：它同时销售“省额度”这件事。

**核心功能**

- 接入宿主提供的 hook 采集工具调用；对于没有 hook 的宿主（如 Grok Bot），改为监听聊天日志文件，确保也能采集到调用记录。会话记录会按日期写入记忆日志，不需要用户手写笔记。
- 原始工具调用先由 LLM 压缩成语义摘要再存入记忆库，使用时通过 MCP 搜索工具按需取回片段，避免把整段历史重新塞进上下文、消耗 token。
- 记忆压缩时的模型调用不占你的 Anthropic 套餐额度：可以用项目自建 observer，也可以填自己的 OpenRouter/Gemini key，README 声称这样最多能把套餐用量省出一倍。
- 把 observation 按类型分成 decision、bugfix、security_alert、sensitive 四类，称为 needle，再以 `- YYYY-MM-DD \[awareness\] …` 的格式追加进 memory/log/YYYY-MM.md。某些宿主本来就会重读这个文件，因此注入不需要额外成本。

**适用场景**: 适合长期用 Claude Code、Codex、OpenCode 反复改同一个仓库的开发者——跨会话时不用再重讲架构决策、踩过的坑和安全红线；团队也可以靠它把项目记忆沉淀下来共享。

**竞品对比**: 和 mem0、Letta\(MemGPT\)、Zep 这些通用记忆层比，claude-mem 不需要你改代码调 SDK，而是安装在宿主侧，通过 hook 自动采集；和手写 CLAUDE.md/AGENTS.md 比，它是自动生成、按需检索，而不是每轮都全量塞进上下文。

**成熟度**: 版本已到 15.8.0，迭代频繁，文档翻译了 30 多种语言，有 Vercel OSS、Greptile、SerpApi 赞助和付费托管版，日常可用；但计费策略和宿主适配还在快速变动。

**趋势信号**: 编程 Agent 已从单一 CLI 变成 Claude Code、Codex、OpenCode 多平台混用，跨会话丢失上下文成为共同痛点；这次更新也集中接入了 Grok Bot、T3 Code、Antigravity、OMP 等新宿主，把新平台的用户都吸引了过来。

### [pbakaus/impeccable](https://github.com/pbakaus/impeccable)

 `Rust` ⭐ +1,338 今日新增 · 98,505 总星数

> 给 AI 编码助手提供一套设计词汇和规则库：用 24 个命令调整界面风格，用 62 条不依赖 LLM 的规则拦截 AI 生成的同质化丑设计。AI 写前端泛滥后，设计质量成了新瓶颈。

**亮点**

- 把“审阅”和“生成”分开：不指望模型一次写对，而是承认模型只能写出“得体的默认风格”（Inter 字体、细衬线、胶囊按钮），然后用一套外部规则和具名命令去反复改。同模型、同需求、加不加它，输出的页面是两个档次——README 直接贴了对比图
- live 模式的闭环落在源代码上，而不是截图或 Figma：在浏览器里选中一个元素，热替换变体，接受后写回你的文件，绕开了“改设计要重跑整个 prompt”这个低效步骤

**核心功能**

- 检测器用 Rust 写成，62 条规则全部为确定性规则，不调用大模型、不需要 API key。扫描源码（JSX/TSX 只跑模式类规则）或扫描渲染后的 URL（用本机 Chrome/Edge，跑对比度、字号这类必须有渲染树才能判断的规则）
- 把原本停留在提示词层面的设计动作拆成 24 个具名 playbook，比如 bolder/quieter/distill/polish/harden，每个命令只针对一个具名目标执行；先执行 init 读代码生成 PRODUCT.md 和 DESIGN.md，后续命令都读这两个文件，保证改动不跑偏
- 提供 agent 钩子：agent 每改完一个 UI 文件就自动扫描，并在 agent 宣布“做完了”之前把问题回传给它，不需要人工记得去跑检测；另有 live 模式，在 Vite/Next/SvelteKit/Astro/Nuxt 开发服务器的页面上叠加浮层，选中元素后循环换变体，选中即写回源码

**适用场景**: 使用 Claude Code、Cursor、Codex 等工具生成前端页面的开发者，尤其是自己不做设计、又不想交付“Inter 字体 + 紫蓝渐变 + 卡片套卡片”那套默认风格的人；也可放进 CI，用 npx impeccable detect --github 做告警，或装 Chrome 扩展给任意线上页面打分。

**竞品对比**: 可访问性和对比度这块和 axe-core、Lighthouse 重叠，但 Impeccable 主要针对审美同质化（62 条规则里有专门识别“过度使用的字体”“嵌套卡片”“彩色底上的灰字”这类 AI 惯用套路）以及设计动作的术语化；和 v0、Lovable 方向相反——那些是生成新页面，它是审阅、迭代已有界面。

**成熟度**: 工具链已经齐了（CLI、CI 注解、Chrome 扩展、多编辑器安装器、文档站和案例），但设计规则和命令语义还在快速迭代，实际是“能用但要跟着版本走”的状态。

**趋势信号**: AI 生成 UI 的同质化（俗称 AI slop）已经被广泛吐槽，而这个项目刚好卡在编码 agent 大规模接管前端、设计质量成为最后瓶颈的时间点上。

**亮点**

**竞品对比**: 对标 xAI Grok Bot、Meta Muse、OpenAI dots、Manus Cue 这些闭源个人 agent；最大差别是自带已有订阅登录、每个 bot 可以配不同厂商模型、数据留在本地，而不是锁死一家模型外加厂商云 VM。

**成熟度**: 有签名公证的多平台安装包，但项目靠一堆“open XX alternative”博客页做 SEO 起量，宿主控制还缺 Wayland 支持，按早期项目看待，接口和行为都可能变。

**趋势信号**: 2026 年初 Grok Bot、Meta Muse、OpenAI dots、Manus Cue 接连发布且全是闭源，社区正在搜“开源替代”，这个项目用对应关键词的落地页接住了这波搜索流量。

**亮点**

**成熟度**: 很早期，README 明说"very very early, expect bugs"，暂不接受大功能 PR，也还没有文档站，不建议放进关键生产流程。

**趋势信号**: 作者是知名主播 Theo（t3.gg），项目刚上架 App Store 和 Google Play，赶上 2025 年下半年"多 Agent 并行 + 手机远程盯任务"这波需求爆发。

**竞品对比**: 和 Gamma、SlidesAI 这类 AI 做 PPT 的工具比，它产出的是带语音讲解和互动环节的整节课，不是幻灯片；和可汗学院 Khanmigo 比，它开源、可自部署、可换模型。最大差异是离线 HTML 导出，能脱离服务器直接播放。

**成熟度**: 已到 v1.3.0，MIT 协议，有 JCST'26 论文、完整文档和 Discord/飞书社区，近期密集发安全公告并修复 SSRF 等问题；但 1.2.0 起有破坏性变更且不能回滚到 1.3.0 以下，升级前必须读 changelog。

**趋势信号**: 2026-10-29 的 v1.3.0 把知识库和 Pro 工作台上线，加上 1.2.x 连续接入 Kimi、DeepSeek、Firecrawl 联网搜索，正好踩在 AI 生成课件和「教育 Agent」这波热度上。

## 趋势观察

今天的榜单几乎被一件事占满：给 AI 编程助手上管理。有人补长期记忆，有人开源自己天天用的 agent 技能包，有人把 Claude Code 拆成 49 个子代理、按总监主管专员三层分工，还有人做远程控制台，用手机管电脑上跑的 Agent。共同点很清楚——模型会不会写代码已经不是瓶颈，怎么组织它才是。Claude Code 刚补齐 subagents、skills、hooks 三件套，社区一周内就把配套工法全做出来了。这很像当年 npm 生态起来的样子，只不过这次打包的不是库，是流程和规范。 第二个信号是反同质化。24 个命令调界面风格、62 条规则拦 AI 生成的丑设计，说明 AI 写前端已经泛滥，审美和一致性成了新瓶颈。 第三，垂直场景开始被做成引擎和数据。紫微斗数放出 67.5 万张命盘数据集，AI 家教做长期学习记忆，课堂生成平台直接产出一整节课。门槛从会不会做，降到有没有想法。 第四是成本。Lightpanda 用 Zig 重写无头浏览器，不渲染像素，内存只有 Chromium 的十六分之一，冲的就是 Agent 大规模爬页面这笔账。用得越多，越要算得起。 再加上一堆本地优先、不订阅、无遥测的小工具，能看出开发者的口味：要可控，要能改，数据得自己拿得住。这波热潮里真正被抢的不是模型，是工作流。
