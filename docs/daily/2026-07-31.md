- 已在生产环境作为数千台 Reachy Mini 机器人的对话后端

**核心功能**

- VAD->STT->LLM->TTS 四阶段级联，每阶段可插拔，线程+队列实现低延迟
- OpenAI Realtime 兼容 WS API，客户端零改动切换自托管/云端 LLM
- 默认 STT 用 Parakeet TDT，TTS 用 Qwen3-TTS，支持 GGML/MLX/CUDA 多后端

**适用场景**: 需要构建本地、低延迟语音助手或机器人的开发者；尤其适合隐私敏感场景和嵌入式设备（如 Reachy Mini 机器人）。

**竞品对比**: 与 OpenAI Realtime API 直接竞争，但完全开源可自托管；相比 Vosk 等传统语音框架，集成 LLM 和流式 TTS，提供现代对话体验。

**成熟度**: 项目较新但已在生产环境支撑数千台机器人，API 稳定度中等，文档较全。

**趋势信号**: Hugging Face 推出与 OpenAI Realtime 兼容的开源方案，迎合本地优先、隐私保护和自主 AI 趋势，刚发布即获得大量关注。

### [agavra/tuicr](https://github.com/agavra/tuicr)

 `Rust` ⭐ +1,901 今日新增 · 1,901 总星数

> 终端里的代码审查 TUI，带 vim 键位，支持 GitHub/GitLab 推送及面向 AI 代理的 Markdown 导出。

**亮点**

- 单一静态 Rust 二进制，自带 tuicr update 自更新机制（支持 Homebrew/Cargo/Mise/Nix）
- 评论导出为带文件行锚点的 Markdown，专门为编码代理设计，可粘贴给 Claude/Codex/Cursor
- 库封装 ReviewStore，第三方工具可用同一原语添加评论，实现协作式审查

**核心功能**

- GitHub 风格连续 diff 流，一次滚动查看所有变更文件
- 行/范围/文件/审查四级评论，支持 git、jj、Mercurial 三种 VCS
- 持久化审查会话，自动跳过已评论提交，提供 Rust 库 API 和 review CLI

**适用场景**: 适合在终端里做深度 code review 的开发者，尤其是使用 jj/hg 或需要把评论推送到 GitHub/GitLab MR/PR 的场景；也适合配合 Claude/Codex 等编码代理，通过剪贴板或 stdout 传递结构化评论。

**竞品对比**: 比 hunk 和 lumen 多了完整 vim 键位和 GitLab 推送；比 gh pr review 支持内联评论；且是唯一支持 Mercurial 的 TUI 审查工具。

**趋势信号**: AI 编码代理流行带动'人审+代理审'工作流，tuicr 的 agent-ready 导出能力踩中需求；加上 Rust TUI 生态热度，发布当天即获大量 star。
