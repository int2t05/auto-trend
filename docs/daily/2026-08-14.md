**亮点**

**趋势信号**: 端侧AI和工具调用模型成为热点，Needle 2以极小体积实现类似大模型功能，正好踩中手机厂商和IoT对私有化、低延迟的需求。

### [NVIDIA-NeMo/Switchyard](https://github.com/NVIDIA-NeMo/Switchyard)

 `Rust` ⭐ +408 今日新增 · 1,250 总星数

> 一个 Rust 写的 LLM 流量代理，能在 OpenAI 和 Anthropic API 间互转，让 Claude Code、Codex 这类工具直接换用开源模型，还支持多模型路由和监控。刚发布几天就火了。

**亮点**

- 用 Rust 写代理层，比常见 Python 网关（如 LiteLLM）开销更低，翻译和转发都在原生性能下完成。
- 把路由逻辑和模型调用彻底解耦：算法只做决策，不拥有 HTTP 栈，所以能嵌入任何现有系统，而不是只能跑独立服务。

**核心功能**

- 协议翻译：在 OpenAI Chat、Anthropic Messages、OpenAI Responses 三种格式之间双向转换，客户端保持原生 API，后端随便换 vLLM、NIM、Ollama。
- 四种路由算法：随机（A/B 测试）、LLM 分类器（按请求内容分强弱模型）、Stage Router（按对话里的工具结果等信号路由，不额外调模型）、升级路由（先弱后强，由裁判决定是否重跑），还能用 Rust 自己写。
- 嵌入式设计：switchyard-libsy 库不启动 HTTP 服务，只返回路由决策，模型调用交给宿主程序，可直接塞进现有网关或 Agent 运行时。

**适用场景**: 用 Claude Code、Codex CLI 或 OpenClaw 的开发者，想把这些工具接到开源模型（vLLM、Ollama、NVIDIA NIM）或 OpenRouter 上，顺便做多模型 A/B 评测、控制成本或按信号自动换模型。

**竞品对比**: 类似 LiteLLM、OpenRouter 这类 API 网关/代理，但 Switchyard 专门针对编码 Agent（Claude Code、Codex），原生兼容 Anthropic Messages 和 OpenAI Responses 两种协议，且用 Rust 实现，差异化在 Agent 场景和性能。

**成熟度**: 明确标注 pre-alpha，不推荐生产使用，API 和算法在 v1.0 前会大改，但文档齐全、有官方发布渠道。

**趋势信号**: NVIDIA 官方出品，正好赶上 Claude Code/Codex 用户想换开源模型的热潮，今天新增 408 星，可能是刚发布被社区发现，解决的是真实存在的协议锁死痛点。

> holehe 是一个 Python 工具，通过网站忘记密码功能检查邮箱是否注册了 Twitter、Instagram 等 120+ 站点，且不会向目标邮箱发送通知，常用于 OSINT 调查。

**亮点**

- 不触发邮件提醒：通过模拟忘记密码流程，分析响应内容而非依赖邮件发送，避免打草惊蛇

**核心功能**

- 采用模块化设计，每个网站一个独立模块，统一输出 JSON，便于扩展和集成
- 利用密码找回接口的响应差异判断账号是否存在，全程不发邮件，隐蔽性强
- 基于 trio + httpx 实现异步请求，支持并发检查多个站点

**适用场景**: 安全研究人员、调查记者或社工测试者，需要快速确认一个邮箱关联了哪些网络账号，用于数字足迹梳理或钓鱼攻击面分析。

**竞品对比**: 与 socialscan 类似，但 holehe 覆盖站点更多，且明确聚焦不发送邮件，隐蔽性更强。

**成熟度**: 较成熟，PyPI 长期维护，有稳定版本和下载量，但部分站点可能因接口变化失效。

**趋势信号**: 原因不明，可能与开源情报（OSINT）工具在安全社区持续走热有关。

### [altic-dev/FluidVoice](https://github.com/altic-dev/FluidVoice)

 `Swift` ⭐ +76 今日新增 · 9,897 总星数

> macOS 上的本地语音听写应用，用设备端 STT 模型把说话转成文字，支持 AI 增强和语音控制 Mac。开源免费，是商业 Wispr Flow 的本地替代，主打隐私和低延迟。

**亮点**

- 能把命令模式和写模式分开：语音既能全局控制 Mac（启动应用、跑快捷指令），也能在任意文本框内插入或重写文字
- 通过 macOS 辅助功能 API 直接向任意应用插入文本，绕开了各应用对剪贴板粘贴的限制

**核心功能**

- 内置 NVIDIA Parakeet 的自研实现，宣称几乎零延迟，说话和出字几乎同步
- Fluid Intelligence 本地 AI 模型做智能格式化、上下文大写和后处理，数据不出本机
- 支持切换多种语音模型（Nemotron、Whisper、Cohere、Apple Speech 等），按语言和延迟选

**适用场景**: 需要快速听写的开发者、作家、医生等，在 Mac 上不想用云端服务，又嫌 Wispr Flow 贵，想要本地离线、隐私可控的语音输入工具。

**竞品对比**: 相比商业的 Wispr Flow，最大差异是开源 GPLv3、本地优先、支持多模型，且核心功能免费。类似项目还有 MacWhisper 和 Superwhisper，但 FluidVoice 把命令控制和 AI 增强整合进来了。

**成熟度**: 生产可用，1.6.0 版本持续更新，有 Homebrew 安装、自动更新，社区活跃，但 Fluid Intelligence 增强模块未开源。

**趋势信号**: 最近发布 1.6.0，加入近乎零延迟的 Parakeet 实时模型和完全本地的 Fluid Intelligence，正好撞上用户对付费 AI 听写工具（Wispr Flow）的替代需求浪潮。
