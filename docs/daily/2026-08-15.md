> Needle 2 是一个 45M 参数（14MB 二进制）的工具调用和结构化提取模型，可在 28MB 内存运行，面向手机、手表、智能家居和机器人等端侧设备。

**亮点**

- 权重烤进单个 engine，推理零网络请求，离线或气隙环境可直接部署。

**核心功能**

- 用 Simple Attention Network（Hadamard MLP + GQA + engram 键值记忆）压缩到 CQ2 位量化，45M 参数打包成 14MB 单文件引擎。
- 从用户声明的 JSON Schema 编译成字节级语法，解码时限制每个 token，工具调用直接输出结构化 JSON。
- 内置置信度评分头和工具检索头，每轮只渲染 top-5 工具，配合 256 token 滑动窗口做 KV 固定，总内存稳定在 28MB 附近。

**适用场景**: 需要端侧设备做工具调用和结构化数据提取的开发者，比如智能家居控制、手机助手和机器人指令解析；用 Python 装饰器描述工具，模型自动选函数、填参并返回 JSON。

**竞品对比**: 与 FunctionGemma 270M、LFM2.5 230M、Apple FM 等小模型对比，Needle 2 体积小 5-70 倍、仅 2 bits，但基准互有胜负。
